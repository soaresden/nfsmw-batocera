NFS Most Wanted pour Batocera

Cette page prépare le jeu pour Batocera (Retroid Pocket 5 et autres consoles ARM64) à partir de votre copie Xbox 360. Tout se fait dans votre navigateur : aucun fichier du jeu n'est envoyé.

Navigateur

Pour écrire directement sur la carte SD ou le partage réseau, ouvrez cette page avec Chrome ou Edge sur un ordinateur. Ici, la page fabrique un zip à décompresser vous-même, et vous copiez les fichiers du jeu à la main (il faut alors le dossier extrait de l'ISO).

1 Votre jeu

L'ISO Xbox 360 du jeu, telle quelle. Un dossier déjà extrait (avec default.xex, NFS/ et Movies/) ou un dossier NFS Most Wanted.sh déjà installé conviennent aussi.

    VF (facultatif)

    Avec l'ISO de la Xbox d'origine en français, la page passe le jeu en VF : textes, 32 des 36 vidéos et les voix en jeu. Outil french-dub de nfsmw-nx, exécuté dans le navigateur.

      Éditions reconnues
      Édition Xbox 360Port BatoceraVF

      « Bientôt » : le port d'une édition se compile une fois à partir de son default.xex. Si vous avez une de ces éditions, ouvrez un ticket sur la page du projet (sans joindre le fichier : c'est le jeu).

      2 Où l'installer

      Le dossier roms/ports de Batocera : sur la carte SD branchée au PC, ou le partage réseau \\BATOCERA\share\roms\ports (connecté comme lecteur réseau).

        3 Préparer

        La page déchiffre le port avec votre default.xex, fabrique les shaders, les trois styles d'icônes (PlayStation, GameCube, Xbox 360) et les images pour la fiche EmulationStation, puis écrit le dossier NFS Most Wanted.sh. Comptez quelques minutes, plus la copie du jeu.

        Terminé

        Sur la console : redémarrez EmulationStation (ou la console), puis lancez NFS Most Wanted dans Ports. Les options sont dans Options avancées du jeu → NFS MOST WANTED. Hotkey + Start quitte le jeu, Hotkey + L1 fait une capture.

        Pour un retour : envoyez nfsmw-stdout.log et data/logs/ du dossier du jeu.
