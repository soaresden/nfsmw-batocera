      Éditions reconnues

      « Bientôt » : le port d'une édition se compile une fois à partir de son default.xex. Si vous avez une de ces éditions, ouvrez un ticket sur la page du projet (sans joindre le fichier : c'est le jeu).

      2 Où l'installer

      N'importe quel dossier : la page y crée NFS Most Wanted.sh. Le plus simple est le dossier roms/ports de Batocera (carte SD branchée au PC, ou partage réseau \\BATOCERA\share\roms\ports) ; sinon, copiez ensuite le dossier dedans. Un dossier NFS Most Wanted.sh existant peut aussi être choisi directement.

        3 Préparer

        La page déchiffre le port avec votre default.xex, fabrique les shaders, les trois styles d'icônes et les images de la fiche EmulationStation, écrit le dossier NFS Most Wanted.sh, copie le jeu, puis fait la VF si vous l'avez demandée.

        Terminé

        Sur la console : redémarrez EmulationStation (ou la console), puis lancez NFS Most Wanted dans Ports. Les options sont dans Options avancées du jeu → NFS MOST WANTED. Hotkey + Start quitte le jeu, Hotkey + L1 fait une capture.

        Pour un retour : envoyez nfsmw-stdout.log et data/logs/ du dossier du jeu.

        Code source et explications : nfsmw-batocera (GPL-3.0), à partir de nfsmw-nx et NFSMW Android Evolved. Black Edition : patch de tuhana (xenia-canary/game-patches), repris par Epix Digital Studio. VF : outil french-dub de nfsmw-nx. Le port est chiffré : seul le default.xex de l'édition l'ouvre.
